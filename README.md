# ReelInsights

This project contains the TMDB data cleaning, SQL analysis, pandas analysis, and visualization workflow.

## Structure

- `data/` - raw and processed datasets
- `01_data_cleaning.ipynb` - data cleaning notebook
- `02_sql_analysis.ipynb` - SQL analysis notebook
- `03_pandas_analysis.ipynb` - pandas analysis notebook
- `04_visualizations.ipynb` - visualization notebook
- `app.py` - main application entry point

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```
